FrontWars - About

FrontWars is a commercial game developed and maintained by VexxusArts Ltd. It is partially based on the MIT-licensed portions of the OpenFrontIO project created by OpenFront LLC.

FrontWars does not include any GPL or AGPL code. All incorporated code originates only from OpenFrontIO commits that were entirely MIT-licensed.

UPSTREAM CODE REFERENCE

FrontWars includes modified portions of OpenFrontIO code taken exclusively from two fully MIT-licensed commits:

Commit 9d5c108b83937a30ab42de6b1dca5a64e577aaac
